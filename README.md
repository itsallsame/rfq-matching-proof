# RFQ matching proof

A self-built, runnable **synthetic demonstration** of a bounded electrical-parts
RFQ-to-quotation pipeline. This is not a client case, commissioned work, or a
live n8n integration.

## Run

Python 3.10+:

```sh
python -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python quote.py output/pdf/synthetic-rfq.pdf catalogue.csv --output output
.venv/bin/python -m unittest -v test_quote.py
```

The supplied PDF is text-based and uses one explicitly supported layout:
`line | product code | description | quantity | unit`, inside a `LINE ITEMS` /
`END ITEMS` section. An unknown or malformed item row aborts extraction.
Actual client layouts need separate scoping and validation; this is not a
general PDF table extractor or OCR implementation.

## Inspect the proof

- [Synthetic RFQ PDF](output/pdf/synthetic-rfq.pdf): seven invented line items.
- [Approved synthetic catalogue](catalogue.csv): prices and units are supplied,
  never generated by a model.
- [Excel-compatible CSV draft](output/quotation-draft.csv): all seven requested
  rows, source page/text-line coordinates, draft/review state, and reasons.
- [Detailed machine-readable report](output/report.json).

Expected result: **3 draft rows, 4 review rows, EUR 81.60 draft subtotal**:
`4 × 12.50 + 3.5 × 8.40 + 2 × 1.10 = 81.60`.

The unknown code, mismatched unit, negative quantity, and ambiguous catalogue
code receive **no price**. There are no automatic substitutions or unit
conversions. Even exact matches remain drafts for human approval. Different
currencies have separate subtotals. Formula-looking CSV text is escaped for
spreadsheet import; the JSON preserves the original values.

## Boundaries and costs

This proof runs locally with open-source Python packages, without hosting or
paid API calls. It outputs CSV, **not XLSX**. n8n orchestration, workbook layout,
new PDF formats, deployment, ERP connections, automatic sending and support
are not implemented or tested here. A production quotation requires sample
files, approved matching/rounding rules and a separately agreed paid scope.
No order or income has resulted from this demonstration.
